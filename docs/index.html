// Open a workbook. Work with typed columns.
f, err := xlsx.Read(file, xlsx.Options{})
if err != nil {
    return err
}

// Every operation returns a new frame.
groups, err := f.GroupBy("region")
if err != nil {
    return err
}
summary, err := groups.Aggregate(
    sheetframe.Aggregation{
        Column: "revenue",
        Op:     sheetframe.Sum,
        As:     "total_revenue",
    },
)
BUILT WITH CLEAR EDGES

In-memory, eager operations. Excel imports read cached formula values; they don’t calculate formulas. Exports create a fresh workbook of values. Read the scope & limitations ↗
