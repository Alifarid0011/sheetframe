FROM FIRST QUESTION TO A RESULT

Start with a sample.

  1. Choose a workflow in the playground. Inspect its CSV or download the original data.
  2. Click Run sample view. The filter, grouping, and sort controls show exactly what Go will run.
  3. Change a control and apply again, or open your own CSV / Excel file. Download the result as CSV or Excel.

Each transformation starts from the loaded source. Clear transformations returns to that source; it does not undo your CSV edits. To load edits, click Load CSV.

Bring a small, tidy table

Use comma-separated CSV or .xlsx with one nonblank, unique header per column in the first row. Blank cells become null. Pick the Excel sheet before opening the file; otherwise the first sheet is used.

Something not loading?

Wait for “Go + WebAssembly · ready” before importing. If the engine is unavailable, reload and check that your browser allows WebAssembly. For a local checkout, build with bash scripts/build-demo.sh and serve docs/ over HTTP; opening the HTML directly will not load the engine.

For an import error, check the headers, matching CSV field counts, and Excel sheet name. A failed import leaves the last successful dataset available. Start with a smaller file if the tab becomes slow.

Continue in Go

Install Sheetframe v0.2.0 below with Go 1.25 or later. For saved notebooks with Go cells, see GoBook and its local setup guide ↗.

BUILT WITH CLEAR EDGES

This demo runs eager, in-memory operations on your browser’s main thread. Start with small files: large or compressed workbooks can use much more memory than their file size and make the tab unresponsive. There is no guaranteed dataset capacity. The preview shows at most 200 rows; exports include every result row. CSV infers numeric-looking identifiers (leading zeros can be lost); integers outside the exact float64 range are rejected. Use typed XLSX text for identifiers. Excel imports read cached formula values; they don’t calculate formulas. Exports create a fresh workbook of values, without the original formatting or formulas.
