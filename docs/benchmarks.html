What these numbers mean

The input has three columns: 20 repeated string groups, float64 amounts from 0 to 999, and boolean flags. Input creation, imports, startup, result conversion and checksum validation are outside the timer. Excel I/O is not measured. All operations produce native DataFrame results; selection can share buffers and filters can use indexed views.

pandas is shown with both its default Python-backed string dtype and an explicit object string column. Optional PyArrow is absent. Polars uses eager operations and stable ordering. QFrame’s incompatible unstable sort is omitted; its group case includes a timed sort to match group order for this dataset.

Sheetframe 0.2 replaces JSON key construction with typed hashing and streamed aggregates. Large numeric columns use stable radix sorting, which consumes extra temporary memory. The native allocation benchmark reports that tradeoff separately.

A single synthetic, null-free workload cannot establish the fastest library for every job. Thread count, strings, cardinality, nulls, data distribution and hardware can change the result. Read the methodology and native allocation results, rerun the benchmark, or inspect every raw sample.
